<a id="p01-300-degree-variant"></a>
### P01 — DS041MG 300° 行程版本

#### Raw Source Faithful Reproduction（原始证据忠实复刻）

> 我弄错了，按照300版本来计算

#### Engineering Statement
> [CONFIGURED] 项目使用者撤销先前的 180° 版本记录，并将 StackForce 腿部舵机的当前计算配置指定为 `DS041MG 300°` 版本。

#### Source Observation
- 用户明确指出先前版本信息有误，并要求采用 300° 版本计算。
- 包装铭牌照片 `E-HW-005` 本身没有印出行程角度，因此 300° 版本由独立的项目配置记录承载。

#### Engineering Interpretation
- 命令角换算、仿真初值和相关名义计算采用 300° 版本。
- 固件 API 将 `500–2500μs` 映射为 `0–300°`，与当前版本配置在名义角度范围上相符；这只构成配置一致性，不等同于物理端点已经实测验证。
- 安全关节范围仍需结合机械干涉、舵盘零位和 PWM 端点单独标定。

#### Limitations
- 尚无该 300° 版本的正式数据手册、独立版本标签或购买记录。
- 尚未通过量角、编码器或运动捕捉实测输出轴的有效行程。
- 不能据此假设每个装机舵机在 `500–2500μs` 下均能安全覆盖完整 `0–300°`。
